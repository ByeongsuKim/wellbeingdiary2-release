# 성장일기 설치 파일

초개별화 맞춤교육을 위한 Windows용 AI 도우미 **성장일기**의 배포 저장소입니다. (소스 코드는 비공개)

## 설치

1. 오른쪽 [Releases](https://github.com/ByeongsuKim/wellbeingdiary2-release/releases/latest)에서 `GrowthDiary-Setup-버전.exe`를 내려받습니다.
2. 내려받은 파일을 실행합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (코드 서명 인증서가 없는 앱이라 나오는 안내입니다.)
3. 설치 위치를 고르고 [설치]를 누르면 진행률이 표시되고, 끝나면 앱이 실행됩니다.

## 업데이트

새 버전이 나오면 앱을 실행할 때 "새로운 버전이 있습니다. 업데이트 하시겠습니까?"라고 묻습니다. **[예]**를 누르면 자동으로 내려받아 설치합니다.

## 데이터

대화, 학생 정보, 설정은 `%APPDATA%\성장일기`에 저장되며 업데이트하거나 삭제해도 지워지지 않습니다.
